# 1. Descripción del caso de negocio

El sistema tiene como propósito gestionar y dar trazabilidad al ciclo productivo de los cuyes de distintas razas en el **laboratorio de crianza de cuyes en la Facultad de Zootecnia (UNAS)**, desde su nacimiento o ingreso hasta su venta, descarte definitivo o muerte. Actualmente, los procesos se registran manualmente en cuadernos separados y luego los datos se trasladan a un excel para elaborar reportes y registros de cada cuy. Esto demanda tiempo adicional y, cuando las actividades no se anotan oportunamente, genera información incompleta o desactualizada que dificulta el seguimiento de cada animal y el control del criadero.

La propuesta consiste en una plataforma web modular que centralice los registros de nacimientos, camadas, destetes, etapas productivas, movimientos de jaula, empadres, partos y controles sanitarios. También permitirá registrar pesos muestrales por camada o grupo, comparar el inventario físico con el registrado y consultar el historial de cada cuy mediante un código único y filtros de búsqueda.

La encargada registrará las actividades operativas, mientras que la gerente consultará indicadores, reportes y alertas sobre destetes, separaciones de empadre, fechas probables de parto y desparasitaciones pendientes. De esta manera, el sistema reducirá el trabajo manual y facilitará el acceso a información organizada y oportuna para mejorar el manejo y la toma de decisiones del laboratorio.
