## Resumen del Proyecto

- **65 historias de usuario** (41 núcleo + 24 cuyes)
- **3 entregas** priorizadas (P1, P2, P3)
- **12 sprints** de 2 semanas
- **Stack:** React + Node.js + PostgreSQL

3. Seguir [azure-devops-setup.md](azure-devops-setup.md) para configurar Azure DevOps
4. Usar [guia-azure-devops.md](guia-azure-devops.md) si necesitas ayuda con la herramienta
